# 프로젝트 에이스 · Project Ace (판매용 에디션)

브라우저에서 바로 하는 3D 공중전 게임 (three.js). 이 저장소는 **팔 수 있게 정리한 판매용 에디션**이에요.

## 새로 들어간 것

- **39개 언어** — 처음 켜면 언어를 고르는 화면이 나와요 (메뉴 → 🌐 언어 · Language 에서 언제든 바꿀 수 있어요). 한국어 · English · 日本語 · 简体中文 · 繁體中文 · Español · Français · Deutsch · Português · Русский 등. 영어는 사람이 직접 다듬었고, 다른 언어는 기계 번역에 격납고·메뉴 핵심 용어를 손으로 고쳐 넣었어요.
- **워썬더식 격납고** — 위쪽 출격 버튼과 모드 선택, 왼쪽 아이콘 줄, 오른쪽 접히는 패널(성능 · 도색 · 정비), 아래쪽 국가 탭과 기체 카드. 국가 탭: 미국 · 소련/러시아 · 영국 · 독일 · 프랑스 · 일본 · 중국 · 스웨덴 · 대한민국 · 캐나다 · 기타.
- **유럽식 시골 마을 13곳 + 밭**: 박공지붕 집(회반죽 · 반목조 · 돌 · 벽돌), 첨탑 교회, 헛간, 돌담 · 산울타리, 과수나무, 마을길과 마을을 잇는 시골길, 둥근 건초 더미. 마을 둘레엔 산울타리로 나뉜 밭(밀 · 보리 · 유채 · 갈아엎은 밭 · 목초지)이 펼쳐져요. 집은 폭탄 · 미사일에 무너지고, 들이받으면 추락해요.
- **격납고 음악 「출격 전야」** — 직접 작곡한 오케스트라 행진곡(호른 · 트럼펫 · 트롬본 · 현악 · 합창 · 팀파니 · 스네어). 녹음 파일 없이 게임 안에서 실시간으로 합성돼요. 비행 중에는 음악 없이 엔진 · 무전 · 경고음만 나와요.
- **설정 → 📜 크레딧 보기** — 모델 제작자 · 라이선스 · 음악 · 엔진 크레딧을 언제든 볼 수 있어요 (☰ 메뉴에도 있어요).
- **멀티플레이 아군 사격 금지** — 같은 편끼리는 총알 · 미사일 · 폭탄 피해가 안 들어가요.
- **실제 같은 배 항적** — 켈빈 파(19.47° 쐐기, 가로파 + 사선파, 꼭짓점 줄이 제일 밝음)와 프로펠러가 만드는 흰 거품 줄, 그 뒤로 길게 남는 매끈한 물길.

## 판매용 에디션에서 바뀐 점

- **다른 게임에서 뽑아낸 3D 모델은 하나도 없어요.** 설명에 War Thunder · Ace Combat · Battlefield 2 모드 · Cold Waters · Return to Castle Wolfenstein · World of Warplanes · Rise of Flight 에서 가져왔다고 적혀 있거나 "Not my model"이라고 적힌 모델은 전부 뺐어요.
- 깨끗한 모델이 예전에 있던 기체는 그 모델로 돌아갔어요 (F-15C, F/A-18C, F-4E, F-5E, A-10, Su-25, Su-34, 라팔, 타이푼, J-10, 미라주 2000, 2차대전 프로펠러기 등).
- 깨끗한 모델이 아직 없는 기체는 격납고 목록에서 빠졌어요 (MiG-21, F-104, 토네이도, 해리어, 스핏파이어 등). 미션에서 그 기체가 나올 자리에는 비슷한 깨끗한 기체가 대신 나와요. 깨끗한 실사 모델을 찾는 대로 다시 넣을게요.
- 헬기는 MH-60L 하나만 남았어요. 지상전 전차는 게임 자체 전차 모델로 나와요.
- Tu-95는 원작자(helijah)의 원본 모델을 써요.
- 대회판의 '카카리코 마을' 모델(젤다 게임에서 뽑아낸 것)은 빼고, 그 고원에 직접 만든 유럽 마을을 지었어요.
- 장난 기능은 뺐어요: 기관포 5초 연사 핵, 7667 무적 모드, 'L을 가져가' 춤.
